# Roleta

Projeto de estudo de uma roleta de prêmios animada, desenhada em `<canvas>` com JavaScript.

🔗 **Demo:** https://matheusdiamantino.github.io/Roleta-Jogo-de-Apostas/

## O que foi praticado

- **Canvas 2D**: desenho dos segmentos da roleta e das imagens sobre cada fatia
- Animação de giro com `requestAnimationFrame` e desaceleração suave (easing)
- Detecção da passagem do ponteiro pelas bordas dos segmentos
- CSS com luzes animadas ao redor da roleta e layout responsivo
- **jQuery** para o botão "GIRAR"

## Como abrir

Abra o `index.html` no navegador. As imagens das fatias estão como placeholders (`image1`, `image2`) no código.
